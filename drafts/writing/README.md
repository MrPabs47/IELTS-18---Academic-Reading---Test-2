# IELTS Writing visual preview

This folder is the permanent visual-review workspace for the IELTS Writing section.

## Rules

- The preview lives on the isolated `writing-preview` branch.
- Incremental preview commits are allowed on this branch.
- `main`, Reading and Listening are not modified during visual review.
- The same browser URL should be reused after every update.
- The preview is not linked from the IELTS Pabs Live Hub.
- After approval, production changes are prepared on the feature branch and can be squash-merged cleanly.

## Current pilot
